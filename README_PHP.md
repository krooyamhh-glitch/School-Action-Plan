# คู่มือการติดตั้งและใช้งานบน PHP Web Server (Hosting / cPanel / DirectAdmin / XAMPP)

ระบบแผนปฏิบัติการประจำปีและจัดสรรงบประมาณโรงเรียน (ฉบับ Native PHP 8.x)

---

## 📌 สาเหตุที่เปิดหน้าเว็บไม่ได้ในตอนแรก:
ก่อนหน้านี้โค้ดหน้าบ้านเขียนด้วย TypeScript / React (`.tsx`) ซึ่งเว็บบราวเซอร์และ PHP Web Server (เช่น Apache, LiteSpeed, Nginx) **ไม่สามารถอ่านหรือรันไฟล์ `.tsx` ได้โดยตรง** หากไม่มีการ Build หรือไม่มี Node.js รันอยู่เบื้องหลัง

---

## ✅ สิ่งที่ปรับปรุงและเปลี่ยนเป็น PHP 100% แล้ว:
ตอนนี้ระบบถูกพัฒนาเป็น **Native PHP ล้วน** เรียบร้อยแล้ว:
1. **มี `index.php` อยู่ที่โฟลเดอร์หลัก (Root)** เมื่อเปิดโดเมนหรือโฟลเดอร์ ระบบจะเปิดหน้าเว็บได้ทันที
2. ทุกหน้าทำงานด้วยภาษา PHP + HTML + Tailwind CSS (ผ่าน CDN ไม่ต้องติดตั้ง Node.js หรือ npm ใดๆ ทั้งสิ้น)
3. **ระบบผู้ช่วยเขียนโครงการด้วย AI (`ai_project_writer.php`)** ทำงานด้วย PHP cURL เชื่อมต่อ Google Gemini API และดาวน์โหลดเป็นเอกสาร Word (`.doc`) และพิมพ์เป็น PDF ได้ทันที
4. มีระบบ **Offline / Demo Mode**: แม้ยังไม่ได้ต่อฐานข้อมูล MySQL ระบบก็เปิดหน้าเว็บดูข้อมูลตัวอย่างและทดลองร่างโครงการได้ทันที ไม่เกิด Error หน้าขาวแน่นอน

## 🚀 ขั้นตอนการติดตั้งบน Web Hosting / cPanel

### 1. อัปโหลดไฟล์ขึ้น Server
- อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดนี้ ไปไว้ที่ `public_html` (หรือโฟลเดอร์ย่อย เช่น `public_html/school/`)
- ตรวจสอบว่ามีไฟล์ `index.php`, `.htaccess`, โฟลเดอร์ `config/`, `includes/`, `api/`, `database/` อยู่ครบถ้วน

### 2. นำเข้าฐานข้อมูล MySQL (ถ้าต้องการบันทึกข้อมูลจริง)
1. เปิด **phpMyAdmin** บนโฮสติ้งของคุณ
2. สร้างฐานข้อมูลใหม่ เช่น `school_budget_db` (กำหนด Collation เป็น `utf8mb4_unicode_ci`)
3. คลิกแท็บ **Import (นำเข้า)**:
   - นำเข้าไฟล์ `database/schema.sql` (สร้างตาราง)
   - นำเข้าไฟล์ `database/seed.sql` (ข้อมูลตัวอย่าง สพฐ.)
4. เปิดไฟล์ `config/database.php` แล้วแก้ไขข้อมูลการเชื่อมต่อ:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'ชื่อฐานข้อมูลที่สร้าง');
   define('DB_USER', 'ชื่อผู้ใช้ MySQL');
   define('DB_PASS', 'รหัสผ่าน MySQL');
   ```

### 3. เปิดใช้งานผ่านเบราว์เซอร์
- เข้าชมเว็บไซต์ของคุณ เช่น:
  - `http://your-domain.com/` หรือ
  - `http://your-domain.com/school/`
- ระบบจะเข้าสู่หน้าแดชบอร์ดทันที!

## 🤖 การใช้งานระบบ AI ร่างข้อเสนอโครงการ
1. ไปที่เมนู **"7. เขียนโครงการด้วย AI"**
2. เลือกแม่แบบโครงการยอดนิยม หรือพิมพ์ชื่อโครงการและงบประมาณที่ต้องการ
3. คลิกปุ่ม **"ตั้งค่า Gemini Key"** เพื่อใส่ Google Gemini API Key ของคุณ (ขอรับฟรีได้ที่ [Google AI Studio](https://aistudio.google.com/app/apikey))
4. กดปุ่ม **"ให้ AI ร่างข้อเสนอโครงการ สพฐ."**
5. ระบบจะร่างเอกสารฉบับสมบูรณ์ 13 หัวข้อตามระเบียบ สพฐ. พร้อมตารางงบประมาณ 4 หมวด
6. สามารถกด **"ดาวน์โหลด Word (.doc)"** หรือ **"พิมพ์ / PDF"** หรือ **"บันทึกเข้าแผนงาน"** ได้ทันที
